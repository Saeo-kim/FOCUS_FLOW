Install FOCUS FLOW

Install FOCUS FLOW so it opens in its own window from your desktop, Start menu, or home screen. It uses the same account and the same data as the browser version.

Installation needs the app to be opened over HTTPS (or on localhost). Sign in first, then follow the steps for your device.

Chrome (Windows, Mac, Linux, Android)

  1. Open the FOCUS FLOW address in Chrome and sign in.
  2. Click the install icon at the right end of the address bar, or open the menu (⋮) and choose Install FOCUS FLOW.
  3. Confirm with Install. The app opens in its own window and can be pinned to the taskbar or home screen.

Microsoft Edge (Windows, Mac)

  1. Open the FOCUS FLOW address in Edge and sign in.
  2. Open the menu (…) and choose Apps, then Install this site as an app.
  3. Confirm with Install. Edge adds FOCUS FLOW to the Start menu and taskbar.

iPhone and iPad (Safari)

Installing on iOS works only from Safari, not from other iPhone browsers.

  1. Open the FOCUS FLOW address in Safari and sign in.
  2. Tap the Share button (square with an arrow).
  3. Scroll down and tap Add to Home Screen, then Add.

If the install option does not appear

  • Check that the address starts with https://.
  • Reload the page once, sign in, and try again. The browser offers installation after the app's service worker is active.
  • Private or incognito windows usually do not offer installation.
